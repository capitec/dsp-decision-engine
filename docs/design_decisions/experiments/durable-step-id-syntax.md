# Which durable step id survives refactors without making source noisy?

Date: 2026-09-30 · Script: spike, not kept (behaviour is pinned by tests of `decikit ids`)

## Purpose
Pick an id syntax and format, then prove it against the real engine and a real source rewrite.

## Method
Rendered the id on all ten declaration shapes, simulated rename, extraction, reorder and copy-paste, lowered each shape to IR, and spliced ids into a fixture in a temporary git repo (single-line, multi-line, bare `@step`).

## Result
- Every shape carries the id to `Origin.id`; name, path, `step_map` and output are unchanged. A reused step keeps one id at two paths.
- `dag(single)` dropped the id by collapsing, so collapse now requires no name and no id.
- A byte-splice kept comments and formatting, was idempotent, and aborted without writing on a syntax error or a dirty tree.
- 100k random 48-bit tokens had no collision; two branches adding 1000 ids each were disjoint, so they merge without conflict.
- One known form needed normalising: a multi-line call whose closing paren trails the last argument.

## Decision
Optional `id="..."` on every constructor and decorator, random 12-hex, generated by a clean-tree byte-splice: [lab-and-mcp](../decisions/lab-and-mcp.md).
