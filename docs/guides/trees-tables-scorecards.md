# Trees, tables and scorecards

!!! note "Draft"
    Outline only.

Decision logic kept as data in a JSON document instead of code.

- `TreeConfig`: decision trees and flat rule sets
- `DecisionTableConfig`: bands and rate cards, inline or retuned like a param
- `ScorecardConfig`: points scorecards
- Literal values versus param references
- Shipping your own step type in a package
