# Steps, params, run and score

!!! note "Draft"
    Outline only.

Write a calculation as a function, tune it with params, run it over a frame or score one record.

- A step is a function: inputs, outputs, `missing_as`
- `param()` and the params document
- `flow` (written order) versus `dag` (dependency order)
- `run` over a frame, `score` over a dict
- Modes: interpreted, stepped, fused
- Rounding, money and decimals
- Parameter tables with `param_table`
